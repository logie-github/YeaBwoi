# Ghost flight

Releasing your spirit automatically puts you on the game's Swift Spectral Gryphon, on both
3.3.5a realms. It grants mounted flight for the trip back to your body without requiring a learned
mount or riding skill. Reconnecting as a ghost restores it. Resurrection removes it.

The module uses the client's existing spell 55164 and model; it adds no client files or learned spells.
