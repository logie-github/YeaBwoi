World of Warcraft app: server data tools for Windows

These are AzerothCore's data tools (map_extractor, vmap4_extractor, vmap4_assembler,
mmaps_generator), built from the same source as the server in the app.

1. Unzip this folder anywhere on the PC.
2. Drag your World of Warcraft 3.3.5a (12340) folder onto extract-server-data.bat,
   or run:  extract-server-data.bat "C:\Games\World of Warcraft 3.3.5a"
   It takes from half an hour to a few hours (mmaps, the pathfinding, are the slow part).
3. Copy server-data.zip (made next to the .bat) to the phone, outside cloud folders.
4. In the app: Game files, Import server data, and pick server-data.zip.
